Alpine Linux APK Repository

Unofficial, automated package builds and upstream mirrors for Alpine Linux (v3.24+)

Available Packages
soft-serve Git server for CLI / TUI
es-de EmulationStation DE frontend
umu-launcher Windows games via Proton
unrar RAR archive extraction utility
Installation

1. Trust the repository public signing key:

wget -O /etc/apk/keys/jheronimus-82bae039.rsa.pub https://jheronimus.github.io/repo/alpine/jheronimus-82bae039.rsa.pub

2. Add the repository to /etc/apk/repositories:

echo "https://jheronimus.github.io/repo/alpine/v3.24/main" >> /etc/apk/repositories

3. Update and install:

apk update
apk add soft-serve es-de umu-launcher unrar
